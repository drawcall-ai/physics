# @drawcall/physics-fem

Prepare cached reduced FEM soft bodies from Three.js solids in Node or browsers, then simulate them with `@drawcall/physics-mujoco`. Load GLTS, glTF or GLB assets, or prepare an existing mesh.

The shipped [physics-fem skill](skills/physics-fem/SKILL.md) shows how to prepare, mount, validate, and deploy a component.
