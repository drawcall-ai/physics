# @drawcall/physics-fem

Prepare reduced FEM soft bodies from Three.js solids in Node or browsers, cached ahead of visitors by the vitecache Vite plugin, then simulate them with `@drawcall/physics-mujoco`. Create the solid inline in a cached load, or prepare an existing mesh.

The shipped [physics-fem skill](skills/physics-fem/SKILL.md) shows how to prepare, mount, validate, and deploy a component.
